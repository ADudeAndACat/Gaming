# Source Code Directory

This directory contains all the main application source code organized into functional modules.

## Modules

- **api/** - NHL API client and interaction layer
- **collectors/** - Data collection modules for fetching NHL data
- **database/** - Database models, connections, and migrations
- **analytics/** - Statistical analysis and data processing engines
- **visualizations/** - Chart generation and visualization components
- **web/** - Web interface (API routes, templates, static files)
- **utils/** - Shared utility functions and helpers

Each subdirectory contains its own README.md with specific details.
